Alina Martin - Personal Portfolio Website

A modern, responsive portfolio website showcasing my skills, projects, education, and contact information. Built with HTML and CSS featuring separate pages for easy navigation and editing.

Features
- Multi-Page Structure- Separate HTML files for each section for easy editing
- Working Contact Form - Integrated with Formspree for direct email submissions
- Responsive Design - Works perfectly on desktop, tablet, and mobile devices
- Modern UI- Clean design with Lavender (#C8B6FF) and Deep Purple (#6A4C93) color scheme
- CV Download - Easy access to download my CV from multiple locations
- Interactive Elements- Hover effects, clickable project cards, and smooth transitions
- No Redirect Form - Custom success message without leaving the page

 Pages
1. home.html- Introduction, quick links, and call-to-action buttons
2. about.html- Personal story, values, journey, and languages
3. skills.html- Technical skills with visual progress bars
4. projects.html- Showcase of work including perfume business and IT projects
5. education.html- Academic background and work experience timeline
6. contact.html- Working contact form and contact information
