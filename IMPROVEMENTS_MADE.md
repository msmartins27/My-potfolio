## 📝 Git Commit Best Practices

Going forward, use clear commit messages like:

```bash
git add index.html
git commit -m "Fix broken GitHub and LinkedIn links"

git add portfolio.css
git commit -m "Add hover effects to project cards"

git add index.html portfolio.css
git commit -m "Make project cards clickable with external links"
```

### Good Commit Message Examples:
- ✅ "Add contact section with clickable email and phone"
- ✅ "Fix navigation to contact page"
- ✅ "Update project cards with GitHub links"
- ✅ "Remove non-functional contact form"
- ✅ "Add hover overlay to clickable projects"

### Bad Commit Message Examples:
- ❌ "update"
- ❌ "changes"
- ❌ "add files via upload"
- ❌ "fix stuff"
